# 邮件群发助手

批量发送邮件的 Windows 桌面工具，由命令行版群发脚本改造而来。免安装、双击即用，邮件模板中的任意内容都可以引用 Excel 表格列。

## 功能特性

- **图形界面**：选表 → 填邮箱 → 写模板 → 发送，四步完成
- **任意列占位符**：主题和正文里写 `{列名}` 即可插入表格对应列，列随时可增减
- **模板高度自定义**：正文为 HTML，可自由排版、加样式；日期列支持 `{日期:%Y年%m月%d日}` 这类自定义格式
- **多格式数据**：支持 .xlsx / .xls / .csv，自动识别收件邮箱列
- **常见邮箱免配置**：163 / 126 / QQ / Gmail / Outlook / 阿里云等 SMTP 自动匹配
- **发送保障**：预览效果、测试发送（发给自己）、发送间隔、随时停止、失败名单一键导出 CSV
- **配置记忆**：主题、模板、SMTP 等设置自动保存，下次打开直接用

## 快速开始

**方式一：直接使用（推荐）**

双击 [`dist/邮件群发助手.exe`](dist/邮件群发助手.exe)，无需安装 Python。

1. 选择收件数据 Excel（每行一个收件人，需有一列列名包含「邮箱」）
2. 填写发件邮箱和**授权码**（不是邮箱登录密码）
3. 用 `{列名}` 编写模板，点「预览效果」或「测试发送」确认
4. 点「开始发送」

**方式二：源码运行**

```bash
pip install openpyxl xlrd
python 源代码/mail_gui.py
```

**方式三：重新打包**

装有 Python 的情况下双击 `build_exe.bat`，产物在 `dist/邮件群发助手.exe`。

## 占位符速查

| 写法 | 说明 | 示例输出 |
|---|---|---|
| `{列名}` | 插入该行此列的值 | `{姓名}` → 张三 |
| `{列名:格式}` | 自定义格式 | `{日期:%Y年%m月%d日}` → 2026年10月15日 |

日期默认 `2026-10-15`，时间默认 `09:30`，数字自动去多余小数点。更多写法见[使用说明.md](使用说明.md)。


## 注意事项

- 授权码需先在邮箱网页版「设置」中开启 SMTP 服务后生成（163 在 POP3/SMTP/IMAP 页，QQ 在「账户」页）
- 发送间隔建议不低于 2 秒，发太快容易被服务商限流
- 正式群发前，先用「测试发送」发给自己确认格式
- PyInstaller 打包的 exe 偶尔被杀毒软件误报，添加信任即可
